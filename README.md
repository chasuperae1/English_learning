# English Learning

一个用于英语学习的项目仓库。

## 学习目标

- 提升英语听说读写能力
- 积累词汇量
- 掌握语法知识
- 培养英语思维

## 学习资源

### 词汇
- 每日单词打卡
- 词根词缀学习
- 常用短语积累

### 语法
- 基础语法规则
- 时态练习
- 句型结构

### 阅读
- 英文文章阅读
- 阅读理解练习

### 听力
- 英语听力材料
- 听力理解训练

## 学习计划

| 时间 | 内容 | 目标 |
|------|------|------|
| 周一 | 词汇学习 | 掌握20个新单词 |
| 周二 | 语法练习 | 复习时态 |
| 周三 | 阅读训练 | 阅读一篇短文 |
| 周四 | 听力练习 | 听力材料精听 |
| 周五 | 口语练习 | 口语表达训练 |
| 周末 | 综合复习 | 本周内容回顾 |
